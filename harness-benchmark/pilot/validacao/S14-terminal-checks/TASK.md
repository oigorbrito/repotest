Crie o script tools\Run-Checks.ps1. Ele executa, em ordem alfabética de nome, cada script da pasta checks, cada um em um processo PowerShell separado, e grava relatorio\resultados.txt com uma linha por check: 'OK <nome>' se o script terminar com código 0, ou 'FALHOU <nome>' se terminar com outro código (nome sem .ps1). Use a pasta do projeto (a pasta acima de tools) como base. Depois de criar o script, rode-o. Ao final, rode .\tests.ps1 e confirme que a saída é PASS.
