Precisamos alterar a função para contar apenas sequências que contenham letras ASCII (A-Z, a-z) ou dígitos (0-9). A abordagem atual divide por espaços em branco, então 'Ola,' e 'mundo!!' são contados como palavras, mas '--' também seria contado como palavra, o que está errado. Também 'a-b' precisa virar três palavras ('a', 'b' e 'c' no caso 'a-b c'), então hífens e pontuação precisam funcionar como separadores.

A solução mais simples e correta é usar uma expressão regular que encontre todas as sequências de caracteres alfanuméricos ASCII e contar as correspondências:

- `[A-Za-z0-9]+` encontra cada sequência contínua de letras ou dígitos.
- Para 'Ola, mundo!!' -> 'Ola' e 'mundo' -> 2.
- Para '-- --' -> nenhuma correspondência -> 0.
- Para 'a-b c' -> 'a', 'b', 'c' -> 3.
- Para '' -> 0.
- Para '123 abc.' -> '123', 'abc' -> 2.

Usei `[regex]::Matches` com a classe explícita `[A-Za-z0-9]` (em vez de `\w`, que incluiria caracteres acentuados e underscore), e mantive a verificação de nulo/vazio.

src\Get-WordCount.ps1
```
function Get-WordCount {
    param([string]$Text)
    if ([string]::IsNullOrWhiteSpace($Text)) { return 0 }
    return ([regex]::Matches($Text, '[A-Za-z0-9]+')).Count
}
```
