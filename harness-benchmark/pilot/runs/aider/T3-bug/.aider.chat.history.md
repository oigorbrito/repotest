#### ﻿Corrija o bug em src\Parse-Csv.ps1. A função Parse-CsvLine separa a linha por vírgulas, mas não respeita campos entre aspas: vírgulas dentro de aspas devem ficar no campo, e "" dentro de um campo entre aspas representa uma aspa. Não altere tests.ps1. Ao final, rode .\tests.ps1 e confirme que a saída é PASS.  

O bug está em `Parse-CsvLine`: ela usa `Split(',')`, que ignora aspas, então vírgulas dentro de campos entre aspas quebram o campo e `""` não vira uma aspa.

A correção é trocar o `Split` por um parser caractere a caractere com uma flag `$inQuotes`:
- Fora de aspas, `,` encerra o campo atual e `"` abre um bloco entre aspas.
- Dentro de aspas, `""` gera uma aspa literal, `"` simples fecha o bloco, e as demais vírgulas e caracteres são mantidos no campo.
- O último campo é adicionado ao final da linha.

Não executei o `.\tests.ps1` (não tenho acesso ao shell). Pelo rastreamento dos quatro casos de `tests.ps1` (`a,b,c`; `a,"b,c",d`; `x,"say ""hi""",y`; `"",z`), a saída esperada é `PASS`. Por favor, rode o teste para confirmar.

src\Parse-Csv.ps1
```
function Parse-CsvLine {
    param([string]$Line)

    $fields = New-Object System.Collections.Generic.List[string]
    $sb = New-Object System.Text.StringBuilder
    $inQuotes = $false

    for ($i = 0; $i -lt $Line.Length; $i++) {
        $ch = $Line[$i]

        if ($inQuotes) {
            if ($ch -eq '"') {
                if ($i + 1 -lt $Line.Length -and $Line[$i + 1] -eq '"') {
                    # "" dentro de campo entre aspas representa uma aspa literal
                    [void]$sb.Append('"')
                    $i++
                }
                else {
                    # aspa de fechamento
                    $inQuotes = $false
                }
            }
            else {
                [void]$sb.Append($ch)
            }
        }
        else {
            if ($ch -eq '"') {
                # abertura de campo entre aspas
                $inQuotes = $true
            }
            elseif ($ch -eq ',') {
                # separador de campo fora de aspas
                $fields.Add($sb.ToString())
                [void]$sb.Clear()
            }
            else {
                [void]$sb.Append($ch)
            }
        }
    }

    # último campo
    $fields.Add($sb.ToString())

    return $fields.ToArray()
}
```
